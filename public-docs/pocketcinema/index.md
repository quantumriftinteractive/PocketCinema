# PocketCinema

PocketCinema turns a Miyoo Mini Plus running OnionOS into a lightweight client for media supplied by a trusted PocketCinema Server (PCServer).

```text
Miyoo PocketCinema -> PocketCinema Server -> Stremio account/addons or Service -> media
```

The Miyoo handles navigation and playback launch. PCServer handles metadata, addon requests, stream selection, compatibility checks, and required media conversion.

Start with [requirements](requirements.md), [installation](installation.md), and [PCServer setup](pcserver-setup.md). See also [browsing and playback](browsing-and-playback.md), [Live TV](live-tv.md), and [troubleshooting](troubleshooting.md).
