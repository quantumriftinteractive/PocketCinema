# PocketCinema v1

PocketCinema lets your Miyoo Mini Plus browse and play media through a
PocketCinema Server running on your computer. The Miyoo provides the controls
and playback screen; the computer handles the heavier preparation work.

PocketCinema Server is also called **PCServer** in this manual.

## Start here

1. [Install PocketCinema Server](install-server.md).
2. [Configure PocketCinema Server](configure-server.md).
3. [Install PocketCinema on the Miyoo](install-miyoo.md).
4. [Connect PocketCinema](connect.md).

If something goes wrong, start with [Troubleshooting](troubleshooting.md).
Technical background is collected in [Advanced / Technical

## What you need

- A Miyoo Mini Plus running a supported OnionOS environment.
- The PocketCinema client installed on the Miyoo.
- PocketCinema Server running on a Windows or macOS computer.
- A trusted network connection between the Miyoo and the computer.
- A Stremio account and compatible addons for account-backed Library, Live TV,
  and account-provided sources. These features are optional, but available
  content depends on that account.

PocketCinema does not require public port forwarding. Tailscale, when used for
remote access, is a separate OnionOS companion application; PocketCinema does
not install, sign in to, or manage it.
